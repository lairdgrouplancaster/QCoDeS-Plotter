# qPlot

qPlot displays QCoDeS measurements, including line plots and heatmaps, with
read-only access to measurement databases.

Start with the [user guide](user-guide.md), explore
[synthetic data and application screenshots](demo-data.md), or consult
[troubleshooting](troubleshooting.md).

Installation, supported platforms and release validation are described in
[distribution and releases](distribution.md). The
[documentation release process](documentation-releases.md) explains the
development and tagged documentation versions.
